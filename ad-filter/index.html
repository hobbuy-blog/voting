// features

何をブロックするか

block
広告ドメイン
Google Ads、DoubleClick、Amazon Advertisingなど主要広告ネットワークをDNS解決前にブロック。
visibility_off
トラッカー
行動追跡・クロスサイトトラッキングを行うドメインを遮断。プライバシーを保護。
security
マルウェア配布元
既知のフィッシング・マルウェア配布ドメインへのアクセスを事前にブロック。
analytics
アナリティクス
Google Analytics等のデータ収集スクリプトが読み込む外部ドメインを遮断。
// how-to-install

インストール手順

01
Safari でこのページを開く
Chrome や Firefox ではプロファイルのインストールができません。必ず Safari を使用してください。
02
「プロファイルをダウンロード」をタップ
ダウンロード確認ダイアログが表示されたら「許可」をタップ。プロファイルがデバイスに保存されます。
03
設定アプリを開く
設定 アプリを開くと最上部に「プロファイルがダウンロードされました」というバナーが表示されます。タップしてください。
04
インストールを完了する
右上の「インストール」→ パスコード入力 → 再度「インストール」→「完了」の順にタップ。以上で有効になります。
05
削除するには
設定 › 一般 › VPNとデバイス管理 からプロファイルを選択して削除できます。いつでも元の状態に戻せます。
